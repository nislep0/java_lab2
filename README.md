## Тема
Рядки в мові програмування Java

## Мета роботи
Ознайомлення з рядками в мові програмування Java та основними методами їх обробки.  
Набуття практичних навичок роботи з текстовими даними типу `String`.

## Завдання
1. Створити текстову змінну типу `String`.
2. Знайти слово в першому реченні заданого тексту, якого немає в жодному з наступних речень.
3. Реалізувати програму мовою Java з використанням типу даних `String`.
4. Вивести результат роботи програми на екран.
5. Обробити можливі виключні ситуації.
6. Дотримуватися стандартів Java Code Conventions.

## Теоретичні відомості

У мові програмування Java рядки представляються класом `String`.  
Цей клас надає широкий набір методів для роботи з текстом, зокрема для:
- пошуку підрядків;
- розбиття рядка на частини;
- перетворення регістру символів;
- видалення зайвих пробілів та символів.

Для аналізу тексту часто використовується розбиття рядка на речення та слова.  
Оскільки символи можуть мати різний регістр і містити розділові знаки, перед порівнянням текст зазвичай нормалізується (переводиться в нижній регістр та очищується від небуквених символів).

## Опис алгоритму

1. Заданий текст розбивається на окремі речення.
2. З першого речення виділяються всі слова.
3. З усіх наступних речень формується набір слів для порівняння.
4. Послідовно перевіряється кожне слово з першого речення:
    - якщо слово не зустрічається в жодному з наступних речень, воно вважається шуканим.
5. Якщо таке слово знайдено - воно виводиться на екран.
6. Якщо жодне слово не задовольняє умову - виводиться відповідне повідомлення.

## Опис програми

Програма реалізована у вигляді одного класу з виконавчим методом `main`.  
Усі змінні оголошені та ініціалізовані у виконавчому методі.

Під час виконання програми:
- здійснюється перевірка коректності вхідних даних;
- обробляються можливі виключні ситуації;
- порівняння слів виконується без урахування регістру символів.

## Результати роботи програми
У результаті виконання програми:
- визначається слово з першого речення, яке не зустрічається в жодному з наступних;
- результат коректно виводиться на екран;
- у разі відсутності такого слова користувач отримує відповідне повідомлення.
